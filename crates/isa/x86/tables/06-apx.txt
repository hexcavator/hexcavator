# Intel APX: EVEX-promoted general-purpose instructions (EVEX map 4, and
# promotions in maps 2, 3, and 7), and the REX2-only instructions.
#
# Sources: the Intel APX Architecture Specification, checked against Intel
# XED's APX data (datafiles/apx-f) and LLVM.
#
# In these forms the last EVEX payload byte holds ND (a new data
# destination, in EVEX.vvvv), NF (no flags), and for CCMP/CTEST the source
# condition; L'L is 0 and there is no masking. Tokens:
#
# | token | meaning |
# |---|---|
# | `NP66` | both NP and 66 (66: a 16-bit operand size) |
# | `ND0` `ND1` `NF0` `NF1` | EVEX.ND / EVEX.NF must be this (ND0, NF0 by default) |
# | `SCC` | CCMP/CTEST: one form per condition, `$cc` in the mnemonic |
# | `rex2` | only with a REX2 prefix |
#
# Attributes: `nf` (NF may be set, shown as `{nf}`), `ndd` (also a form with
# ND = 1 and a new data destination first), `evex` (an EVEX form of a legacy
# instruction: shown as `{evex}` unless NF or ND is set), `evexv` (likewise,
# for VEX and 0F38 instructions, whose other encodings can't reach r16-r31:
# shown only when no such register is used), `norsp`.
